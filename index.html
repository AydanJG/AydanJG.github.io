Internship · Summer 2026

SS&C Technologies — LLM Learning Assistant

Deployed internally

An internal, source-grounded assistant that answers fund-accounting and operations questions for onboarding staff — built to cut new-hire ramp time and reduce interruptions to senior staff.

A retrieval-augmented assistant grounded in curated internal training material, which cites its sources and refuses to answer rather than fabricate when grounding is insufficient. Delivered as a demo-grade v2 proof of concept by a four-person intern team over roughly twelve weeks.

Python FastAPI PostgreSQL pgvector MinIO SSE RAG BM25

What I built

  • FastAPI service streaming responses over Server-Sent Events using delta frames and a done sentinel.
  • A single wire contract abstracting two interchangeable LLM delivery paths behind one endpoint, so the frontend keeps one chat codepath.
  • Self-hosted retrieval pipeline with configurable chunk storage — on-disk via MinIO or a vector-enabled Postgres store.
  • User authentication with role-based permissions backed by PostgreSQL.

Grounding & governance

  • Every answer scored for grounding with a combination of BM25 and cosine similarity.
  • Responses classified as grounded, partially grounded, or ungrounded before being returned.
  • Enterprise AI data-pipeline API integrated as the primary delivery path.
  • All LLM access routed through a governed gateway with full governance headers.

Cites or refuses

No ungrounded answers returned as fact

Delivery path swappable without frontend changes

Personal product

Nitch

In App Store review

A social app for rating, ranking, and sharing real-world experiences — think Beli, but for everything you actually go out and do.

Nitch turns the things you do — restaurants, shows, trips, nights out — into a ranked, shareable record. Instead of star ratings that flatten everything into a 4.2, it uses head-to-head comparison to build a personal ordering, then surfaces recommendations from the people whose taste you actually trust.

TypeScript React Native Expo Supabase PostgreSQL Stripe

What I'm building

  • Cross-platform mobile client in React Native and Expo, written in strict TypeScript.
  • Comparison-based ranking rather than flat star ratings.
  • Social graph and feed so recommendations come from people you know.
  • Supabase backend with row-level security on every table.

Where it stands

  • Currently in Apple App Store review.
  • Invite-only — not yet publicly launched or downloadable.
  • Private codebase, so there's no public repo to link.
  • Actively in development ahead of a wider release.

Computer-vision dance training with real-time pose feedback, alignment scoring, and movement coaching.

LiveDance tracks a dancer from a live camera feed, compares their pose against a reference performance, and delivers corrective feedback on posture, timing, and alignment. I worked primarily on the pose-extraction pipeline powering the real-time feedback loop.
